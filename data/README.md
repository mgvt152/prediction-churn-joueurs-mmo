# Données

Le fichier principal pèse 643 Mo : il n'est pas versionné dans Git.

1. Se connecter à Kaggle et télécharger l'archive du dataset
   [World of Warcraft Avatar History](https://www.kaggle.com/mylesoneill/warcraft-avatar-history).
2. Décompresser l'archive dans ce dossier `data/`.

On doit obtenir :

| Fichier | Contenu |
| --- | --- |
| `wowah_data.csv` | 10,8 M relevés de connexion (char, level, race, charclass, zone, guild, timestamp), année 2008 |
| `zones.csv` | Description des zones du jeu (non utilisé pour l'instant) |
| `locations.csv`, `location_coords.csv` | Lieux et coordonnées (non utilisés) |

Source d'origine : Y.-T. Lee, K.-T. Chen, Y.-M. Cheng, C.-L. Lei, « World of Warcraft Avatar History Dataset », ACM MMSys 2011.
